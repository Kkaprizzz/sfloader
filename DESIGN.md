# SFLoader — дизайн

Направление: **utility / рабочий инструмент** (Transmission, qBittorrent, Parabolic).
Окно — не лендинг. Главный экран: строка ссылки и список. Вид держится на
типографике, линейках и плотности, а не на декоре.

Аудитория: сам автор и друзья. Никаких описаний возможностей, доната, футера.
Язык интерфейса: только русский (строки лежат прямо в компонентах).

## Токены

Определены в `front/src/index.css`.

| Токен | Значение | Где |
|---|---|---|
| `--bg` | `#161617` | фон окна |
| `--surface` | `#1d1d1f` | поле ввода, превью-подложка |
| `--surface-2` | `#252528` | hover строк и кнопок окна |
| `--line` | `#2c2c30` | все разделители и рамки, 1px |
| `--line-strong` | `#3b3b41` | рамка вторичных кнопок |
| `--text` | `#e8e8ea` | основной текст |
| `--text-2` | `#a0a0a8` | вторичный |
| `--text-3` | `#80808a` | подсказки (на `--bg` ≈ 4.6:1) |
| `--accent` | `#3fb950` | единственный акцент: главная кнопка, прогресс, фокус |
| `--accent-ink` | `#06200d` | текст на акценте |
| `--danger` | `#f0605d` | ошибки, только текст и левая линейка |
| `--radius` | `4px` | везде |

Нейтральный графит без оттенка. Один акцент. Зелёный значит «идёт загрузка / можно качать».

## Типографика

- IBM Plex Sans Variable (`@fontsource-variable/ibm-plex-sans`, локально, кириллица есть).
  Рекомендован type.today как единственный годный нео-гротеск с кириллицей.
- Размеры: 13 / 14 / 15, заголовок ролика 16. Вес 400, 500, 600.
- Числа (размер, проценты, длительность, качество) — `tabular-nums`.
- Моноширинный не используем.

## Композиция

```
┌ титлбар 36px: sfloader ................ ─ □ ✕ ┐
├ [ ссылка ........................ ] [ Найти ] ┤  строка ввода на всю ширину
├ превью  Название ролика                       ┤
│         YouTube · 0:19                        │
├ Качество   Размер   Статус          ·········┤  заголовки колонок
│ 1080p      48 MB                    [Скачать] │
│ 720p       22 MB    Скачивание      78%       │  строка с прогрессом (2px снизу)
│ 480p       11 MB                    [Скачать] │
├ Сохранено · Показать в папке                  ┤
```

- Ничто не центрируется, всё выровнено по левому краю окна, отступ 20px.
- Список — строки по 40px, разделитель 1px, без зебры и без карточек.
- Пустое состояние: строка ввода и одна серая строка подсказки.

## Моушен

- Одна кривая: `--ease: cubic-bezier(0.2, 0, 0, 1)`.
- Hover/focus: 150ms. Ширина прогресса: 200ms linear.
- Индикатор поиска — тонкая бегущая линия 2px под строкой ссылки.
- Появления, стаггер, blur, пружины, пульсации — нет.
- `prefers-reduced-motion: reduce` отключает всё.

## Иконки

Свои, сетка 24×24, stroke 1.5, round, `currentColor` (`front/src/components/Icon.jsx`).
Кнопки окна — отдельные плоские 10px-глифы в `TitleBar.jsx`.
Lucide не используем.

## Запреты для этого проекта

- Стекло, `backdrop-filter`, свечение, градиенты, сетка и пульсация на фоне.
- Карточки (включая вложенные), скругление больше 4px, тени.
- Центрированный hero, лозунги, блоки «возможности», нумерация, бейджи-пилюли.
- Inter, Manrope, Roboto и прочее из чёрного списка по кириллице.
- Hover-scale, translateY на кнопках.
