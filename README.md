# SFLoader

Десктопное приложение для скачивания видео. Внутри yt-dlp и ffmpeg, всё работает
локально: ни сервера, ни базы данных, никуда ничего не отправляется.

## Что нужно

Node 20.19 или новее. На 18-м не соберётся — и Electron, и Vite об этом прямо
говорят. Если пользуешься nvm, в репозитории есть `.nvmrc`, так что достаточно
`nvm use`.

## Запуск

```
cd front
npm install
npm start
```

`npm start` поднимает Vite и открывает окно Electron. Для скачивания нужен
yt-dlp: в режиме разработки берётся системный (из PATH), так что убедись, что он
установлен (`yt-dlp --version`).

## Сборка

```
cd front
npm run setup:bin       # один раз: качает yt-dlp в resources/bin
npm run electron:build
```

Результат лежит в `front/release`: AppImage можно просто запускать, deb — ставить
через пакетный менеджер. В собранное приложение yt-dlp зашивается, отдельно его
ставить уже не надо. ffmpeg тянется из пакета ffmpeg-static автоматически.

## Как устроено

```
front/
  electron/    main-процесс: окно, IPC, запуск yt-dlp
  src/         интерфейс на React
  resources/   бинарь yt-dlp для сборки (в гит не коммитится)
```

Интерфейс не имеет прямого доступа к Node — общается с системой только через
IPC, описанный в `electron/preload.cjs`.

## Если не запускается на Linux

На Wayland у Electron падает GPU-процесс. Приложение само перезапускается на X11,
но если что-то пошло не так, запусти вручную:

```
npm run dev
# во втором терминале:
./node_modules/.bin/electron . --ozone-platform=x11
```
